> 计划周期：2026 年 10 月 3 日—2027 年 1 月 31 日

> 求职定位：以 Java/Spring Cloud 后端能力作为基本盘，使用 LightRAG、Python FastAPI 和 MCP 构建差异化能力。

## 一、总体目标

在 2027 年 1 月 31 日前完成以下准备：

- 一个可运行、可部署、可演示的 Java + AI 主项目；
- 一套 Docker Compose 一键启动环境；
- Java 后端和 Python AI 服务之间的完整调用链；
- 100～200 条 RAG 评测数据；
- 一份后端压测报告和一份 RAG 评测报告；
- 完整 README、架构图、接口文档；
- 3～5 分钟项目演示视频；
- Java 后端版简历和 AI 应用后端版简历；
- 70～90 道高频算法题；
- 40～60 道 Java、数据库、Redis、MQ、AI 项目面试题；
- 至少两次模拟面试；
- 2027 年 1 月中旬开始实际投递。

核心策略：

> 以 Java/Spring Cloud 后端能力作为求职基本盘，完成一个企业级主项目；再用 LightRAG、Python FastAPI 和 MCP 做出差异化。2027 年 1 月中旬开始投递，不等所有准备“完美”后再投。

### 1.1 执行方法：边学边做，但分阶段引入技术

本计划不是“先连续学习几个月，再开始项目”，也不是“第一周就同时开发 Spring Cloud、LightRAG 和 MCP”。正确方式是：每周先学习完成本周任务所需的知识，再立即应用到同一个主项目中。

```text
学习本周需要的知识
       ↓
完成小型练习验证理解
       ↓
立即应用到主项目
       ↓
编写测试、更新文档、复盘问题
```

主项目按照以下顺序逐步生长：

```text
第1～4周：Spring Boot单体项目
       ↓
第5～9周：Spring Cloud微服务项目
       ↓
第10～12周：接入FastAPI与LightRAG
       ↓
第13周：增加MCP工具服务
       ↓
第14周：完成全链路集成
       ↓
第15～17周：测试、部署、简历与投递
```

各阶段的边界如下：

- 第 1～4 周只做 Java 基础、Spring Boot、MySQL、Redis 和单体业务，不提前接触完整微服务及 AI 模块；
- 第 5～9 周在已有单体业务基础上学习并实践 Spring Cloud、Kafka、权限、监控和压测；
- 第 10～12 周再学习 FastAPI、LightRAG、检索策略和 RAG 评测，并接入已经完成的 Java 平台；
- 第 13 周开发 MCP，它是副项目能力，不能拖慢主项目；
- 第 14～17 周停止无边界扩展功能，重点完成集成、测试、部署、项目表达和投递。

## 二、主项目设计

### 2.1 项目名称

**企业知识库与智能工单平台**

不直接把现有商城项目改名，而是参考成熟开源项目的工程架构，自行实现知识管理、智能问答与工单协同业务。

### 2.2 整体架构

```text
前端/接口调用
     ↓
Spring Cloud Gateway
     ↓
认证服务 ── 用户、租户、RBAC权限
工单服务 ── 创建、分派、状态流转、催办
知识服务 ── 文档元数据、上传、权限、版本
     ↓ Kafka
Python AI服务 ── 文档解析、LightRAG、混合检索、问答评测
     ↓
MCP Server ── 查询工单、检索知识库、创建工单、获取统计
```

### 2.3 建议技术栈

- Java 21、Spring Boot 3.x、Spring Cloud；
- Spring Cloud Gateway、Nacos、OpenFeign；
- MySQL、MyBatis-Plus；
- Redis；
- Kafka；
- MinIO；
- Python、FastAPI、Pydantic；
- LightRAG；
- MCP Python SDK；
- Docker Compose；
- Prometheus、Grafana；
- JUnit、Testcontainers、Pytest；
- GitHub Actions。

## 四、分阶段时间分配

建议每周投入 18～22 小时。下面的时间是阶段性安排，不是要求每周同时学习所有技术。每周学习内容应当严格服务于当周项目任务。

### 4.1 第一阶段：第 1～4 周

目标：学习 Java、Spring Boot、MySQL、Redis，并完成单体版本。

| 内容 | 每周时间 |
|---|---:|
| Java、Spring、MySQL、Redis 学习 | 7 小时 |
| 单体项目开发 | 8 小时 |
| 算法题 | 3 小时 |
| 测试、总结、README | 2 小时 |

此阶段的“项目开发”只包括用户、文档、工单 CRUD、MySQL 表设计、Redis 缓存、基础权限和单元测试。暂时不做 Spring Cloud、Kafka、LightRAG 和 MCP。

第一周可按以下方式分配 20 小时：

| 第一周任务 | 时间 |
|---|---:|
| Java 集合、异常、泛型 | 3 小时 |
| Spring IOC、Controller、Service、DAO | 4 小时 |
| 创建项目并完成基础 CRUD | 7 小时 |
| JUnit 测试 | 2 小时 |
| 算法题 | 3 小时 |
| README 与周总结 | 1 小时 |

第二周可按以下方式分配 20 小时：

| 第二周任务 | 时间 |
|---|---:|

| MyBatis/MyBatis-Plus | 2 小时 |
| 项目数据库设计与实现 | 7 小时 |
| `EXPLAIN` 与查询优化 | 2 小时 |

### 4.2 第二阶段：第 5～9 周

目标：把前四周完成的单体项目改造成 Spring Cloud 微服务，并加入异步处理、权限、监控和压测。

| 内容 | 每周时间 |
|---|---:|
| 微服务、Kafka、权限、监控学习 | 4 小时 |

这一阶段才引入 Gateway、Nacos、OpenFeign、RBAC、MinIO、Kafka、Prometheus 和 Grafana。重点是把已有业务工程化，而不是重新开发一套项目。

### 4.3 第三阶段：第 10～14 周

目标：给已经完成的 Java 平台接入 FastAPI、LightRAG 和 MCP。

| 内容 | 每周时间 |
|---|---:|

| AI 模块开发与 Java 联调 | 10 小时 |

### 4.5 一周内的推荐执行顺序

